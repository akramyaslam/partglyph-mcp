# Security Policy

Partglyph MCP Gateway is a hosted remote MCP service.

This repository contains public setup instructions, examples, and metadata only. It does not contain the production gateway implementation source code.

## Reporting Security Concerns

Report sensitive security concerns to:

```text
hello@partglyph.com
```

Please do not open public GitHub issues for sensitive reports.

Do not include API keys, customer data, credentials, or private operational details in public reports.
